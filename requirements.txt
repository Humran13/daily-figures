# Web Push delivery for correction-request notifications. A REAL, active
# dependency — `pip install -r requirements.txt` (see Dockerfile, which
# runs exactly that) installs it automatically on every build; no manual
# `pip install` step is ever needed after a Docker rebuild/deploy.

# lazily inside a try/except and no-ops gracefully if VAPID_PUBLIC_KEY/
# VAPID_PRIVATE_KEY are unset, so the app starts and runs fully even with
# push unconfigured. This local dev/test virtualenv simply hasn't had
# `pip install -r requirements.txt` re-run since this line was added —
# that's an environment-setup gap, not a packaging gap; a fresh install
# (dev or Docker) always gets it.
